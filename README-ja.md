以前は `Suzaku` と呼ばれていました。

CharmyはPython向けのGUIモジュールです。\
複数の切り替え可能なバックエンドを備えており、軽量で、クロスプラットフォームに対応したGUIアプリケーションの構築を可能にします。

Charmyは現在開発段階です。スターを付けていただけると、私たちのやる気と開発速度の向上につながります。

このREADMEは開発初期段階の暫定版であり、今後変更される予定です。

## 詳細情報

Charmyは現在開発段階のため、設計が完了していないか、今後変更される可能性があります。

このプロジェクトに興味のある方は、私たちのディスカッションに参加することで、進捗状況を確認いただけます。詳細に関しては[今後の予定](#%E4%BB%8A%E5%BE%8C%E3%81%AE%E4%BA%88%E5%AE%9A)をご覧ください。

## 進捗状況

初めに、基本的なアーキテクチャについて説明します。\
Charmyは、下層から順にバックエンド層、グラフィック層、ウィジェット層の3つの層に分かれるように設計されています。

現在、バックエンドとグラフィックレイヤーの基本機能はほぼ完成しており、 `/tests/graphics.py` を実行することで動作を確認することが出来ます。

## Genesisバックエンド

Genesisはユーザーに公開される上位のGUI APIを開発している間、一時的に使用されるバックエンドです。

Genesisバックエンドは、レンダリングにCairo、ウィンドウ操作にSDL2を使用しています。
